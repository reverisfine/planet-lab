# 은또링쌤의 행성탐사대

특성화고 「성공적인 직업생활」(직업탐구영역 · 2027 수능 대비) 인출 학습 웹앱입니다.
토픽 하나가 별 하나, 강 하나가 별자리 하나. 개념을 익힐수록 천구의 별자리가 채워집니다.

**접속 주소** → https://reverisfine.github.io/planet-lab/

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (학습 데이터 포함) |
| `README.md` | 이 문서 |

외부 라이브러리 없이 HTML 파일 하나로 동작합니다. 웹폰트(Noto Sans KR)만 구글에서 불러옵니다.

## 배포 방법

1. 이 저장소에 `index.html`을 올립니다
2. **Settings → Pages → Source**를 `main` 브랜치 / `/ (root)`로 지정합니다
3. 1~2분 뒤 위 주소로 접속됩니다

파일을 수정해 다시 올리면 자동으로 반영됩니다. 학생 기기에 이전 버전이 남아 있으면 새로고침을 안내해 주세요.

## 앱 구조

```
홈          검색 · 이어서 학습 · 천구 · 오답노트 · 다시 볼 토픽 · 수능 필수 5강
 └ 강        대분류(I·II·III) 아코디언
     └ 중분류  1·2·3
         └ 토픽  학습 화면
```

**학습 화면**은 세 가지 모드를 세그먼트로 전환합니다.

| 모드 | 화면 |
|---|---|
| 인출 | 빈칸만 보임 |
| 힌트 | 첫 두 글자가 민트색으로 |
| 정답 | 전체가 채워지고 핵심 수치가 빨간색으로 |

판정(알아요 / 헷갈려요 / 몰라요)은 오답노트에 자동으로 쌓이고, 헤더의 갈피 아이콘으로 따로 북마크할 수도 있습니다.

학습 기록은 **학생 기기 브라우저에만** 저장됩니다. 서버가 없어서 교사가 진도를 확인할 수는 없습니다.

## 학습 데이터 수정하기

`index.html`을 열면 **517번째 줄부터** 학습 데이터가 나옵니다. 그 위에 작성 규칙이 주석으로 적혀 있습니다.

### 데이터 4종

| 이름 | 역할 |
|---|---|
| `GANGS` | 강 번호 → 강 이름 |
| `CORE` | 홈 상단 "수능 필수"로 띄울 강 번호 |
| `UNITS` | 강 → 대분류 → 중분류 → 토픽 id 배치 |
| `TOPICS` | 토픽 본문 |

### 토픽 한 개의 형태

```js
{ id:'L17-09',                 // 고유 ID · 중복 금지
  g:17,                        // 강 번호
  t:'구직급여 수급 요건 4가지',    // 토픽 이름
  b:'law',                     // book=교재 수록 / law=법령 확인 / note=해설 보충
  s:'고용보험법 제46조',          // 근거 조문 (선택)
  n:1,                         // 숫자 토픽이면 1 (선택)
  x:['26수능 5번'],              // 기출 이력 (선택)
  p:'L17-10',                  // 헷갈리기 쉬운 짝 토픽 (선택 · 양쪽 모두 지정)
  k:['항목1','항목2'] }          // 인출할 항목들
```

### 항목 작성 규칙

- `<em>...</em>` 로 감싼 부분은 **정답 모드에서 빨간색**으로 강조됩니다. 핵심 수치·용어에만 쓰세요
- `※ ` 로 시작하는 항목은 **함정·보충 설명**으로 분류되어, 항목 수에 포함되지 않고 힌트에도 나오지 않습니다
- `인출문 || 설명` 처럼 `||` 뒤에 쓰면 **정답 모드에서 ⓘ 버튼**이 생기고, 누르면 그 항목의 설명이 펼쳐집니다
- 토픽에 `d:` 를 넣으면 헤더 배지가 **「설명 보기」 버튼**으로 바뀌고, 누르면 아래에서 시트가 올라옵니다. 줄바꿈은 `\n` 으로 씁니다

중요도 ★는 자동 계산됩니다. 기출 있음 → ★★★, 숫자 토픽 → ★★, 나머지 → ★

### 새 강 추가하기

1. `TOPICS`에 토픽을 추가
2. `UNITS`에 강 번호 키를 만들어 트리에 배치
3. 필요하면 `CORE` 조정
4. `DATA_VERSION` 올리기

## 데이터 자가 진단

앱을 열 때마다 데이터를 검사해서, 문제가 있으면 **홈 상단에 빨간 상자**로 알려 줍니다.

- 토픽 ID 중복
- 트리에 배치되지 않은 토픽
- 트리가 존재하지 않는 토픽을 가리킴
- 항목이 비어 있음
- 짝 토픽이 한쪽만 지정됨
- 강 이름이 없는 강 번호

이 상자는 학생에게도 보이므로, 뜨면 바로 고쳐 주세요.
쉼표·따옴표 같은 문법 오류로 데이터를 아예 못 읽으면 별도 안내 화면이 뜹니다.
